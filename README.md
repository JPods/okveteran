# OK Veteran

[okveteran.com](https://www.okveteran.com): an opinion site of an Oklahoma veteran (Bill James, West Point 1972,
infantry veteran). It sets out his personal approach to ending oil wars, climate change and traffic, and to building
viable communities.

- `index.html`: The Approach. One idea (individual sovereignty), the root cause (unconstitutional Federal highways), three
  paths to war, the remedy (Divided Sovereignty, repeal the 17th, the jury), the build (JPods, WebClerk), and a directory
  of the related sites.
- `elections-2026.html`: Elections 2026 (Nov 3, 2026). Why State sovereignty over elections matters, seven questions for
  every candidate, and links to the OK Voter Portal. No endorsements.
- `style.css`: shared styles (Oswald + Source Serif 4; light and dark).
- `images/`: from ~/Documents/KeyDocs/ai_images (JPods AI infographics).
- `CNAME`: www.okveteran.com for GitHub Pages.

Sources for the content: DividedSovereignty.com (incl. /act, /2026-elections, /reportof2026), ClimateChangeRootCause.com,
postRoads.com, TyrannyOfTheMajority.com, JPodsTX.com, TulsaMobilityCompany.com, and ~/Allie/readmes/11-bill-sovereignty-framework.md.
